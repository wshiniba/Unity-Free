二、开发沟通约定

1. 主要测试场景优先使用 TestScence。
2. 用户希望 Inspector 中新增参数都有中文 Tooltip 标注。
3. 用户偏好手动搭建 UI Canvas，再由脚本绑定引用，不喜欢 UI 全部由代码自动生成。
4. 新功能不要只停在方案，除非用户明确说“先别改代码”。
5. 如果改了场景、预制体或资源，应刷新 Unity 并保存。
6. 不要随意删除或回退用户已有改动。
7. 当前项目中有一些文档和脚本迁移痕迹，处理前先查现有文件位置。

五、主要输入约定

鼠标左键：
发射/控制左触手。

鼠标右键：
发射/控制右触手。

松开鼠标：
收回触手；如果触手抓着敌人或物体，会按当前速度甩出。

Q：
如果触手末端接触可锚定目标，则固定锚点。
如果已有锚点，则用于拉拽玩家。

E：
触发触手处决。
如果左右触手都连接同一个可处决敌人，优先触发双触手撕裂处决。
否则尝试单触手穿刺处决。

C：
触发弹反窗口。

Space：
跳跃。
目前已加入土狼时间 coyoteTime。

W：
切换悬停。

LeftShift：
紧急停止。

A/D 或 Horizontal：
水平移动和朝向控制。


六、Layer 规则

当前自定义 Layer：
Layer 6：Wall
Layer 7：GroundNoCableBend
Layer 8：GroundNoHook

OdmController 中的主要 LayerMask：

anchorableLayer：
控制触手允许选中并固定为锚点的层。
当前 Player 2 默认值只包含 Wall。

solidLayer：
控制哪些层会被视为实体障碍。
用于触手末端阻挡、末端沿表面滑动、玩家身体防穿模。
当前 Player 2 默认值包含 Wall + GroundNoHook。

groundLayer：
控制哪些层会被玩家判定为地面。
当前 Player 2 默认值包含 Wall + GroundNoCableBend + GroundNoHook。

cableBendLayer：
控制哪些层会让触手中段发生弯折和视觉防穿模。
当前 Player 2 默认值包含 Wall + GroundNoHook。

GroundNoCableBend：
玩家能踩，但触手不会因它弯折。
适合只想让玩家站上去、不影响触手曲线的物体。

GroundNoHook：
行为基本等同 Wall，会阻挡玩家和触手末端，也会让触手弯折。
区别是不会被触手选中并固定为锚点。

重要历史问题：
曾经 GroundNoHook 仍能被 Q 固定为锚点。
原因是代码只判断触手末端是否接触 solidLayer，没有再检查该接触物是否属于 anchorableLayer。
已修复：OdmController 现在记录触手末端接触的 Collider，并在 Q 固定普通表面前检查 anchorableLayer。


七、触手系统当前状态

已实现：
- 按住鼠标持续伸出触手。
- 松开鼠标收回触手。
- 触手最大长度限制。
- 触手末端不穿墙。
- 触手碰到墙不自动固定，按 Q 才固定。

- 触手中段可产生弹性弯曲。

- 松开鼠标可甩出敌人或物体。

- 弹反成功可反弹弹幕，并有短暂停顿和 Shader 白闪。

关键参数位置：
OdmController、OdmVisuals。

grabTenacity 不决定能否抓取，只影响被抓取后的拖拽迟滞。

九、处决系统当前状态

单触手穿刺处决：
- 不需要玩家提前连接敌人。
- 敌人可处决时，按 E 自动飞出触手穿刺敌人。
- 目标在触手最大长度内都可以触发。
- 触手会穿出敌人一段距离。
- 会提高特殊物品掉落倍率。

双触手撕裂处决：
- 需要左右两条触手都连接同一个可处决敌人。
- 按 E 触发。
- 左触手拉左碎片，右触手拉右碎片。
- 敌人沿竖直中心线被撕开。
- 撕裂过程结束后才结算死亡。
- 使用 Shader 分割 Sprite，不需要真实拆模型。

相关 Shader：
Free/Tear Split Sprite

待做：
- 撕裂粒子、血液、音效、碎片消散等表现还没做。
- 不同敌人形状可能需要单独调 executionFragmentSplit 或偏移。

十六、给新会话的建议接手顺序

如果用户说“继续下一步”，建议先确认当前大方向：
1. 是否继续触手手感优化。
2. 是否继续敌人模板。
3. 是否接升级 UI。
4. 是否接配置表。
5. 是否做玩家死亡或 HUD。

如果没有明确方向，优先建议：
1. 优化敌人投掷手感。
2. 梳理敌人模板和配置表接口。
3. 接正式升级 UI。

如果涉及 Layer：
先查 ProjectSettings/TagManager.asset 和 Player 2 的 OdmController LayerMask。
不要只看 Unity 面板印象，LayerMask 很容易因为预制体覆盖或场景覆盖产生误判。

如果涉及触手锚点：
区分以下概念：
- solidLayer：能碰撞/阻挡。
- cableBendLayer：能让触手弯折。
- groundLayer：能踩。
- anchorableLayer：能被 Q 固定为锚点。

如果涉及可交互物：
TentacleInteractableObject 的抓取现在也会受 anchorableLayer 过滤。
想让某个物体能被触手抓取，除了挂组件，还要确认它的 Layer 在 anchorableLayer 里。
