# 美术需求策划案

更新时间：2026-06-22
适用版本：第一张完整样板关

## 1. 美术目标

当前美术目标不是一次做满整部游戏，而是先服务“首个样板关可完整游玩”。

美术需要同时满足三件事：

1. 让触手机动路径一眼可读
2. 让敌人、锚点、危险物和可处决状态足够清晰
3. 在有限资产下建立稳定的黑暗奇幻地下遗迹气质

## 2. 视觉关键词

- 黑暗奇幻
- 地下洞窟
- 破败遗迹
- 绿灰雾气
- 冷湿石壁
- 残骨、触须、祭坛、锁链
- 血色处决高光

## 3. 画面风格原则

### 3.1 背景负责氛围，前景负责可读

- 背景可以复杂，但不能和实体平台抢轮廓。
- 实际碰撞平台要比背景更清晰、更硬、更高对比。

### 3.2 锚点必须独立成视觉语言

- 锚点不能只是普通石头或普通装饰。
- 建议使用冷白或青绿色发光结构，形成“远处一眼可挂”的识别。

### 3.3 处决与弹反要有高对比反馈

- 常态环境偏冷偏暗。
- 处决、命中、弹反瞬间允许出现高亮白、血红或偏暖高光。
- 高光必须短促、明确，不能长期污染画面。

### 3.4 触手与背景不能混色太严重

- 触手线条要和洞窟背景区分明显。
- 如果背景主色偏灰绿，触手建议走偏骨白、苍肉色、暗红边缘或其他明显区分方案。

## 4. 优先级划分

### P0：样板关必须有

1. 玩家基础角色视觉
2. 触手基础表现
3. 三类小怪基础视觉
4. Boss 原型视觉包装
5. 洞窟遗迹基础场景包
6. 锚点与交互物视觉
7. HUD 最小素材
8. 基础命中、处决、弹反特效
9. 掉落物与升级点视觉

### P1：样板关稳定后补

1. 更完整的敌人死亡与处决演出
2. 场景破碎件与动态装饰
3. 更丰富的背景层和雾效层
4. 更完整的 UI 美术套件
5. Boss 分阶段视觉变化

### P2：后续章节扩展

1. 新 Biome 主题包
2. 额外 Boss 套装
3. 更复杂的剧情演出素材
4. 稀有掉落、收藏品和特殊机关视觉

## 5. 角色美术需求

### 5.1 玩家

最低交付目标：
- 一套可稳定用于样板关的角色立绘/动画素材
- 能区分地面、空中、受伤、挥击、摆荡、弹反等状态

建议动作清单：
- Idle
- Run
- JumpUp
- Fall
- Dash/AirDash
- Swing/Pull
- Hover
- Attack
- Hurt
- Death
- ParryWindow

补充要求：
- 角色轮廓要能在深色背景上站住
- 左右翻转后轮廓仍然清晰
- 身体中心和手部动作要支持“触手发射”读感

### 5.2 触手

当前技术路径以 `LineRenderer` + Shader/特效 为主，因此美术重点不是做整根逐帧动画，而是做以下资产：

- 触手线条贴图
- 触手末端头部/尖端视觉
- 发射波浪强化贴图或遮罩
- 命中火花/抽击特效
- 抓取命中特效
- 处决命中特效

要求：
- 触手末端必须比线体更显眼，便于玩家看清当前落点
- 抓住敌人时要有“钉住/缠住/钩住”的视觉确认

## 6. 敌人与 Boss 美术需求

### 6.1 小怪模板 01：追猎徒兵

定位：基础近战追击兵

需求：
- 轮廓轻快，便于玩家理解“可抓、可甩、可处决”
- 受击与死亡反馈要清晰
- 处决状态下轮廓不能太乱，避免读不出中心线

最小交付：
- Idle
- Move
- Hurt
- Death
- Executable/Half-dead 表现

### 6.2 小怪模板 02：重壳执役者

定位：高质量重敌人

需求：
- 体型和轮廓一眼看出“重、难拖、难甩”
- 身体结构适合砸墙和抱摔表现
- 撕裂处决中心线位置要便于控制

最小交付：
- Idle
- HeavyMove
- Hurt
- Death
- Executable

### 6.3 小怪模板 03：孢子祭司/远程单位

定位：远程压制

需求：
- 攻击准备动作清晰
- 投射物来源明显，方便玩家识别可弹反时机
- 轮廓和近战兵差异明显，避免混战中识别困难

最小交付：
- Idle
- Cast
- Move/Float
- Hurt
- Death
- Executable

### 6.4 Boss：遗迹看守者

定位：样板关收尾 Boss

视觉目标：
- 体型明显大于小怪
- 同时带有遗迹机关感和生物压迫感
- 弹幕、陷阱、受击窗口都有明显的视觉切换

最小交付：
- Intro
- AttackA
- AttackB
- Vulnerable
- Hurt
- ParryStun
- Defeat

补充要求：
- Boss 身上应有能暗示“可受击部位”的局部高亮或结构差异
- 如果会生成专属锚点，锚点造型要和普通场景锚点同语系但更强烈

## 7. 场景美术需求

### 7.1 基础场景包

P0 必须有：
- 洞窟墙体模块
- 平台表面模块
- 石柱/断桥/台阶模块
- 古代祭坛模块
- 锁链、骨架、残骸等点缀
- 背景大形体层
- 雾气层

### 7.2 场景交互物

P0 必须有：
- 可抓取石块
- 可抓取残骸
- 升级祭坛/升级终端
- 掉落物基础外观
- Boss 房入口封锁件

### 7.3 锚点

P0 必须有：
- 通用可钩锁锚点
- Boss 房专用锚点变体

要求：
- 锚点在远景中也能被快速识别
- 不能与纯装饰灯、纯装饰碎石混淆

## 8. 特效与 Shader 需求

### 8.1 P0 特效

- 触手发射波动
- 触手命中火花
- 抓取命中反馈
- 投掷撞击反馈
- 弹反白闪
- 处决命中特效
- 撕裂边缘强化
- 掉落拾取反馈

### 8.2 现有 Shader 对应美术配合

#### `Free/Tear Split Sprite`

需求：
- 不同敌人最好预留较清晰的身体中心线
- 敌人轮廓不要严重偏斜，否则撕裂时很难看
- 如有特殊敌人，可单独调 `executionFragmentSplit`

#### `Free/Sprite Parry Flash`

需求：
- 玩家角色主材质要适配白闪表现
- 白闪时不能让角色轮廓完全丢失

## 9. UI 美术需求

当前 UI 目标是最小版，不做复杂堆叠。

P0 必须有：
- 玩家血条底板
- 玩家血条填充
- 缓冲血条样式
- 升级界面基础底板
- 升级按钮/选项块
- 掉落物图标占位
- 处决提示 `E`
- 基础资源数量显示

UI 原则：
- 能看清即可，不先追求豪华框体
- 升级 UI 要强调“当前能不能升”和“升了什么”
- 不要做大面积厚重装饰遮挡画面

## 10. 技术规范建议

### 10.1 尺寸基准

- 继续以 `Player 2` 的物理身高约 `3.45 Unity units` 为关卡比例基准
- 美术出图时优先按游戏内体积关系，而不是按单张图像素想当然放大缩小

### 10.2 Pivot 建议

- 角色与敌人默认底部中点
- 可投掷场景物体按重心或底部中点处理
- 锚点按中心点处理，方便吸附和对齐

### 10.3 分层建议

- 背景层：氛围优先
- 碰撞平台层：清晰优先
- 前景层：谨慎使用，不能遮挡关键判定
- VFX 层：允许短暂抢眼，但不可长期挡视线

## 11. 生产顺序建议

推荐按下面顺序推进，效率最高：

1. 玩家和触手基础视觉
2. 锚点、平台、洞窟遗迹基础模块
3. 三类小怪基础包
4. 基础命中/投掷/弹反特效
5. 升级点、掉落物、最小 HUD
6. Boss 原型包装
7. 处决强化表现
8. 背景和氛围细化

## 12. 最低验收标准

当以下条件满足时，P0 美术可视为通过：

- 玩家能在任何主要房间里清楚看见可用锚点
- 敌人三种模板轮廓能在混战中一眼区分
- 可抓取物和不可抓取装饰不会混淆
- 处决、弹反、投掷命中在视觉上足够明确
- Boss 房既有压迫感，也能看清路线和危险源
- HUD 与升级界面不妨碍战斗读图
