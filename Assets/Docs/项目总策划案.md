# 项目总策划案

更新时间：2026-06-22
项目代称：Free

## 1. 项目一句话定位

《Free》是一款 2D 横版动作游戏。玩家在黑暗奇幻的地下洞窟与遗迹中，依靠双触手进行高速机动、抓取投掷、处决敌人，并通过掉落与成长逐步强化自身。

## 2. 项目核心定位

- 类型：2D 横版动作 + 平台跳跃 + 高机动绳索/触手战斗
- 主视角：单人，关卡推进式
- 当前最适合的版本目标：先做一张完整可玩的样板关，而不是同时铺开整部游戏
- 核心情绪：压迫环境中的高速掌控感，从“被追”逐步转为“猎杀”

## 3. 核心卖点

1. 双触手独立控制
   - 左右触手分别发射、锚定、抓取。
   - 玩家可以同时处理移动、控场、输出和脱离。

2. 高机动战斗一体化
   - 触手不是单纯位移工具，而是战斗主体。
   - 机动、抽击、抓取、投掷、处决串成同一套操作语言。

3. 抓取投掷与环境利用
   - 敌人和场景物体都可成为武器。
   - 战斗不只拼站桩输出，更强调位置、速度和轨迹。

4. 处决演出形成高光时刻
   - 单触手穿刺处决强调快、狠、直接。
   - 双触手撕裂处决强调条件达成后的奖励演出。

5. 成长反馈明确
   - 触手力量、韧性、长度、命中半径可成长。
   - 玩家会明显感觉到机动范围、抓取能力和控场能力提升。

## 4. 玩家核心循环

探索前进 -> 利用锚点高速移动 -> 接敌 -> 抽击/抓取/投掷/处决 -> 获得掉落 -> 升级触手 -> 进入更高强度区域

具体战斗循环建议固定为：

1. 观察地形与锚点
2. 通过机动拉开或切入
3. 用触手抽击试探，或直接抓取目标
4. 将敌人砸墙、互撞、甩出，形成控场
5. 对残血敌人触发处决，获取更高奖励
6. 在补给点或升级点消耗资源，强化下一轮战斗能力

## 5. 玩法支柱

### 支柱 A：机动

- 玩家移动必须始终爽快、直接、可控。
- 触手锚点布局要支持斜向摆荡、拉拽修正、空中续航。
- 地图不能过度拥挤，否则会压垮机动手感。

### 支柱 B：战斗

- 玩家输出方式主要依赖触手速度、位置和敌人质量关系。
- 普通攻击可保留，但不是主卖点。
- 战斗要鼓励“先控场再收割”，而不是平砍硬磨。

### 支柱 C：处决

- 处决是战斗高潮，不是单纯补刀按钮。
- 处决要和风险、站位、连接状态绑定。
- 处决必须带来明确收益：演出、资源、节奏重置。

### 支柱 D：成长

- 成长优先强化触手，不优先做复杂武器树。
- 升级应直接服务于手感提升与战斗选择。
- 资源消耗要简单明了，方便快速验证数值循环。

## 6. 当前版本范围建议

### 当前里程碑：第一张完整样板关

目标是做出一个 15 到 25 分钟的垂直切片，完整跑通：

- 基础移动
- 触手机动
- 小怪遭遇
- 抓取投掷
- 单/双触手处决
- 掉落与临时背包
- 升级点
- 一个 Boss 原型战

### 当前里程碑内建议内容量

- 1 张样板关
- 3 类小怪模板
- 1 个 Boss 原型
- 1 套基础升级界面
- 1 套最小 HUD
- 1 套基础洞窟遗迹美术包

### 当前里程碑外，建议先冻结的内容

- 真正软体物理触手
- 正式存档系统
- 多章节剧情演出
- 大规模物品系统
- 大量 Boss 并行开发
- 多 Biome 同时开工

## 7. 敌人与内容模板规划

### 小怪模板 01：追猎徒兵

定位：基础追击近战兵

作用：
- 教玩家用位移和抽击保持距离
- 适合作为投掷素材和基础处决目标

特点：
- 质量低
- 可被稳定抓取
- 血量较低
- 行为简单，主要负责追近施压

### 小怪模板 02：重壳执役者

定位：高质量重型敌人

作用：
- 强迫玩家使用抱摔、砸墙、环境伤害或处决
- 让“触手力量成长”有明确价值

特点：
- 质量高
- 难抓取或抓取后迟滞明显
- 普通抽击收益较低
- 适合布置在狭长战斗平台或关卡卡口

### 小怪模板 03：孢子祭司/远程喷射体

定位：远程压制单位

作用：
- 强化弹反系统存在意义
- 迫使玩家用垂直机动和快速切入解决威胁

特点：
- 会发射可弹反投射物
- 自身较脆
- 适合与近战兵混编

### Boss 原型：遗迹看守者

定位：样板关结尾 Boss

Boss 目标：
- 强化弹反、锚点切换、空中规避、可受击窗口
- 让现有弹幕、陷阱、钩锁点系统都有落点

Boss 构成建议：
- 阶段 1：弹幕压制 + 侧向位移
- 阶段 2：陷阱封位 + 顶部锚点追击
- 受击窗口：通过弹反、躲过指定招式或清空一轮压制后开放

## 8. 成长与资源规划

### 当前最适合保留的成长线

- 力量：决定可抓取对象范围
- 韧性：决定触手在受击与弹反中的稳定性
- 长度：决定机动半径和处决覆盖范围
- 命中半径：提升抽击容错
- 受击半径：影响触手受击判定表现

### 资源设计原则

- 当前版本只保留 1 到 2 种主要升级材料
- 敌人普通死亡给基础材料
- 处决给额外材料或稀有材料倍率
- 不要在现阶段引入复杂装备、词条、随机品质

## 9. 世界与视觉方向

- 基调：黑暗奇幻、地下洞窟、残破遗迹、潮湿压迫
- 关键词：绿灰雾气、冷色石壁、古代祭坛、骨质/肉质触手、血色处决高光
- 视觉原则：背景压氛围，前景保可读性，交互点必须显眼

## 10. 当前开发优先级

### P0：必须优先完成

1. 敌人投掷手感定版
2. 三类小怪模板立住
3. 首个样板关灰盒跑通
4. 升级 UI 最小版接入
5. 玩家死亡流程和最小 HUD 完成
6. Boss 原型与新触手系统交互整理

### P1：样板关稳定后推进

1. Excel/CSV 配置表导入
2. 掉落表正式化
3. 小怪表现层补强
4. 处决粒子、血液、音效
5. 场景可投掷机关扩展

### P2：后续版本扩展

1. 正式存档
2. 多章节地图
3. 更多成长分支
4. 更多 Boss
5. 深化剧情和演出

## 11. 立项边界规则

后续任何新点子，只有满足以下任意一条，才允许插队进入当前版本：

- 直接提升触手机动手感
- 直接补全战斗闭环
- 直接补全样板关流程
- 直接提升首个 Boss 战完成度

不满足以上条件的新点子，统一进入创意池，不立刻开工。
